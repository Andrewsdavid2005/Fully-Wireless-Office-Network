# Fully Wireless Office Network

## Project Overview

This project demonstrates the design and implementation of a fully wireless office network using Cisco Packet Tracer.

The network provides wireless connectivity to laptops, PCs, smartphones, and a server through a central wireless Access Point. A Cisco 2911 router is used to provide network connectivity and IP addressing.

The project focuses on understanding WLAN concepts, wireless client connectivity, SSID configuration, DHCP, wireless security, and basic wireless troubleshooting.

---

## Objectives

- Understand Wireless LAN (WLAN) architecture
- Configure a wireless Access Point
- Configure SSID and wireless security
- Connect multiple wireless devices
- Configure DHCP for automatic IP addressing
- Test communication between wireless clients
- Understand wireless client association
- Practice wireless network troubleshooting
- Build a simple office wireless infrastructure
